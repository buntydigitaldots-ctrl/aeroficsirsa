  - Sort order.
  - Enable/disable.

1. **Categories**

- Admin can:
  - Add, edit, delete categories.
  - Set segment_id, parent_id (optional), name, slug, description, image.
  - Choose `show_in_menu`, `show_on_home`.
  - Set SEO meta.

  - Category automatically appears:
    - In category dropdowns.
    - On category list page.
    - On home category section (if `show_on_home = 1`).

2. **Products**

- Admin can fully manage each product:

  - Attributes / features.
  - Flags: is_featured, is_new, show_on_home, status.

- **Images:**
  - Upload up to 4 images.
  - Mark primary image.
  - Reorder images.
  - Replace/remove images.
- Once admin adds product & sets status active:
  - Automatically visible in its category page.
